
# Student Record Management System

A beginner-friendly Python project using **SQLite3** to perform full CRUD operations (Create, Read, Update, Delete) on student records.

## 💻 Technologies Used
- Python 3
- SQLite3
- CLI-based interface

## 🔧 Features
- Add new student details
- View all student records
- Search by ID or name
- Update student data
- Delete student entries

## 🚀 How to Run

```bash
python student_record.py
